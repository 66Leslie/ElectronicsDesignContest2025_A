# Three-Phase Inverter and SPWM Control Platform

This repository holds the 2025 National Undergraduate Electronic Design Contest (NUEDC) track-A
entry that won a **National Second Prize**: SPWM control of a three-phase inverter, phase locking,
and data acquisition on an STM32G474, together with PLECS simulation models and hardware
configuration files.

## Repository layout

- **Core/** — startup and peripheral initialisation generated by STM32CubeMX, plus application code.
  - `Core/user/` — user algorithms: key handling, data processing, the SOGI-PLL/QSG phase-locking
    module, and the main control loop.
  - `Core/Src/` — peripheral drivers, OLED display, and supporting code.
- **Drivers/** — STM32G4 HAL and CMSIS device support.
- **cmake/** — build scripts that turn the CubeMX output and user algorithms into firmware.
- **three_phase_spwm.ioc** — CubeMX project file; use it to regenerate peripheral initialisation.
- **A.plecs / Three_phase_inverter.plecs / triple_phase.plecs** — PLECS models of the three-phase
  inverter and its control loops.
- **CMakeLists.txt / CMakePresets.json** — top-level build configuration.

> Note: the repository also contains a branch that uses space-vector PWM (SVPWM) for higher
> modulation utilisation. Switch to that branch to try it.

## Prerequisites

- CMake >= 3.22
- GNU Arm Embedded Toolchain (`arm-none-eabi-gcc`, `arm-none-eabi-gdb`, ...)
- Ninja or Make
- Optional: STM32CubeMX, to edit `three_phase_spwm.ioc` and regenerate code

## Quick build

```bash
# Configure
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=cmake/stm32cubemx/arm-none-eabi.cmake -G Ninja

# Build the firmware
cmake --build build
```

The firmware and intermediate files land in `build/` and can be flashed with ST-Link, OpenOCD, or
any other supported tool.

## Key features

- Three-phase SPWM generator with gate-drive control.
- SOGI-PLL/QSG synchronisation based on second-order generalised integrators.
- Multi-channel ADC current/voltage measurement via DMA sampling, with data processing.
- OLED display and key input for observing run-time state and adjusting parameters.
